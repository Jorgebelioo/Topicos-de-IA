# Requisitos del Sistema

Para ejecutar este proyecto, se necesita tener instalado Python y las siguientes librerías de dependencias.

## Instalación de Librerías

Se puede instalar todos los paquetes necesarios ejecutando el siguiente comando en la terminal:

```bash
pip install deepface opencv-python tensorflow pandas numpy
```

### Detalle de las Librerías Utilizadas

* **DeepFace**: Biblioteca de análisis de atributos faciales y reconocimiento facial.
* **OpenCV (opencv-python)**: Biblioteca para tareas de visión artificial y procesamiento de imágenes.
* **TensorFlow**: Plataforma de código abierto para aprendizaje automático y redes neuronales.
* **Pandas**: Herramienta de manipulación y análisis de datos estructurados.
* **NumPy**: Biblioteca para el soporte de vectores, matrices y funciones matemáticas.
